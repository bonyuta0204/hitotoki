Hitotoki — 小さな瞬間を、あとから探せる記憶へ

カメラ・声・手入力をひとつの Moment にそろえ、画像説明とベクトル検索によって家族の自然な言葉から再発見する、現在のMVP実装です。

ONE MEMORY MODEL

入力方法が違っても、保存されるのは同じ Moment

カメラはVisionの説明文と画像URL、声はShisaの文字起こし、手入力はそのままの文章を持ちます。すべて timestamp・source・description を共有し、同じQdrantコレクションへ入ります。

DEMO BOUNDARY

動画と音声は保存しない

映像から残すのは約8秒ごとのJPEGだけです。音声は最大30秒のWAVをASRへ送り、文字起こしだけをMomentとして保存します。画像ファイルはMVPではローカルディスクです。
